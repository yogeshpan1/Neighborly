This branch contains the implementation of the **Neighborly About-Us Page**, created to showcase the people behind the Neighborly project and their contributions.

**Features**

- About-Us page introducing the Neighborly team.
- Portfolio section for all members involved in the development of Neighborly projects.
- CV download functionality for team members.
- Responsive and user-friendly interface.
- Professional team showcase with member details and contributions.


The purpose of this branch is to provide a dedicated space where users can learn more about the Neighborly team, explore member portfolios, and download their CVs directly.
